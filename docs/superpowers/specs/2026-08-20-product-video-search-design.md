# 제품검색 (분해영상 찾기) 기능 설계

- 작성일: 2026-08-20
- 상태: 승인 대기

## 배경 / 목적

현장 기사가 작업 중 처음 보는 가전/가구를 분해해야 할 때, 분해 방법을 몰라서
막히는 경우가 있다. 제품 사진을 찍으면 AI가 제품을 인식하고, 그 제품의
분해 방법을 알려주는 유튜브 영상을 자동으로 찾아준다. 유튜브에 적절한 영상이
없으면 구글/네이버 검색으로 대체한다.

대상 사용자: 현장 기사 (작업 중 즉석 사용). 고객용 기능이 아니다.

## 사용자 플로우

1. 하단 네비게이션에 "제품검색" 탭 추가 (기존 7개 탭 뒤, 8번째)
2. 카메라 촬영 또는 갤러리에서 제품 사진 선택 (둘 다 지원)
3. Gemini Vision API로 이미지에서 제품명(브랜드+모델명 등) 인식
4. 인식된 제품명을 텍스트 입력창에 채워서 사용자에게 보여줌 — 사용자가
   확인하거나 수정 가능 (인식이 틀리거나 라벨이 흐릿한 경우 대비)
5. "검색" 버튼 클릭 → 검색어를 `"{제품명} 분해"` 패턴으로 고정 생성
6. Supabase Edge Function 호출 → 유튜브 검색 결과(top 5) 수신
7. 결과 화면에 유튜브 영상 카드 목록 표시 (썸네일, 제목, 채널명) — 탭하면
   유튜브 앱/웹으로 이동
8. 유튜브 검색 결과가 0개인 경우, 자동으로 구글 커스텀 검색 결과(top 5:
   제목/요약/링크)를 대신 표시
9. 결과 화면 하단에는 항상 "네이버에서 찾아보기" 버튼을 노출 — 네이버 검색
   결과 페이지를 외부 브라우저로 여는 링크 (API 미사용, 항상 사용 가능한
   수동 대안)

## 아키텍처

### 프론트엔드 (App.jsx에 추가)

- 기존 이미지 추출 패턴([App.jsx:383](../../../app/src/App.jsx#L383)
  `handleImageExtraction`)과 동일한 방식으로 Gemini Vision 호출부를 작성한다
  (base64 인라인 데이터 + 프롬프트, JSON 파싱).
- 신규 상태: 선택된 이미지 파일, 인식/수정된 제품명, 검색 진행중 여부,
  유튜브 결과 배열, 구글 결과 배열, 에러 상태.
- 신규 탭 `currentTab === 'product_search'` 렌더 블록 추가, 하단 네비에
  버튼 추가 (기존 네비 버튼과 동일한 스타일).
- 이미지 인식 실패 시에도 제품명 입력창은 항상 편집 가능하게 두어 사용자가
  직접 입력해서 검색을 진행할 수 있도록 한다 (기능이 막히지 않음).

### 백엔드 (신규 Supabase Edge Function `product-video-search`)

- 기존 `generate-blog-draft`, `send-sms` 함수와 동일한 구조/배포 방식을 따른다.
- YouTube Data API 키와 Google Custom Search API 키+cx는 Supabase 프로젝트
  환경변수(시크릿)에 저장하고 프론트엔드 번들에는 노출하지 않는다. (Gemini
  키는 기존 관례상 이미 프론트에 노출되어 있으므로 그대로 두되, 이번에
  새로 추가하는 키는 노출시키지 않는다.)
- 요청: `{ query: string }`
- 처리:
  1. YouTube Data API `search` 엔드포인트로 `query` 검색, `maxResults=5`,
     `type=video`
  2. 결과가 0개면 Google Custom Search API로 동일 `query` 검색,
     `num=5`
  3. 응답: `{ youtube: [{ videoId, title, thumbnail, channelTitle }],
     google: [{ title, link, snippet }] }` (둘 중 하나는 항상 비어있을 수 있음)
- 외부 API 오류/타임아웃 시 502와 함께 에러 메시지 반환 → 프론트에서
  안내 메시지 + 수동 검색 링크(유튜브/네이버 검색 URL)로 폴백.

## 사전 준비 사항 (구현 전 필요)

- YouTube Data API v3 키: 이미 보유
- Google Custom Search API 키: 이미 보유
- Google Custom Search 검색엔진 ID(cx): **미보유, 신규 발급 필요**
  1. https://programmablesearchengine.google.com 접속
  2. "검색엔진 추가" → 검색 대상: "전체 웹 검색" 선택
  3. 생성 후 "검색엔진 ID"(cx 값) 복사
  4. Supabase 프로젝트 환경변수에 `GOOGLE_CSE_CX`로 등록
- Supabase 환경변수 등록: `YOUTUBE_API_KEY`, `GOOGLE_CSE_API_KEY`,
  `GOOGLE_CSE_CX`

## 에러 처리

| 상황 | 처리 |
|---|---|
| 이미지에서 제품명 인식 실패/흐릿함 | 빈 입력창 제공, 사용자가 직접 타이핑해서 검색 진행 가능 |
| Edge Function 호출 실패 (네트워크/할당량 초과) | 에러 안내 + 유튜브/네이버 직접 검색 링크(수동) 노출 |
| 유튜브 0건 + 구글 CSE도 0건 | "검색 결과 없음" 안내 + 네이버 링크 강조 |

## 범위 밖 (v1 제외)

- 검색 기록 저장/즐겨찾기 — 요청에 없었음, 필요 시 추후 별도 스펙으로 추가
- 네이버 검색 결과를 API로 앱 내 표시 — 네이버 API 키 미보유로 v1은 외부
  링크만 제공

## 테스트 방법

- `npm run dev`로 로컬 구동 후 실제 가전 라벨 사진 몇 장으로 인식 →
  검색 → 결과 표시 확인
- 존재하지 않을 법한 제품명을 강제로 입력해 유튜브 0건 → 구글 CSE 폴백
  전환 확인
- 두 API 모두 0건인 케이스에서 "결과 없음" 안내 확인
- 네이버 링크가 URL 인코딩된 검색어로 정상적으로 열리는지 확인
- Edge Function 배포 후 Supabase 환경변수 미설정 상태에서 에러 처리가
  프론트에 안내로 잘 전달되는지 확인
